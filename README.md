Interactive Humanitarian Data Analysis using Power BI

🔍 **Overview**

This project explores Uganda’s IPC (Integrated Food Security Phase Classification) data through an interactive Power BI dashboard.

The goal was to transform raw data into a simple, visual decision-support tool.

🎯 **Objective**

To visualize food security severity across Uganda and identify high-priority areas that may require humanitarian attention based on IPC classifications.

🛠️ **Tools Used**
Power BI
DAX (Data Analysis Expressions)
GeoJSON (Uganda spatial data)
Data modeling
Data visualization

📊 **Key Features**
- Interactive Uganda IPC severity map
- Current vs projected severity trends
- Top 5 most affected areas analysis
- District/settlement-level breakdown
- Filters for Area and Time Period

📈 **Key Insights**
The Top 5 high-priority areas include:
1. Nakivale
2. Bidibidi
3. Adjumani
4. Rhino Camp
5. Palorinya
Some areas show current values exceeding initial projections

🧠 **Why This Project Matters**

Food security data is often complex and difficult to interpret.

This dashboard demonstrates how data visualization can:

Improve understanding of humanitarian risk distribution
Support prioritization of intervention areas
Enable faster, evidence-based decision-making
